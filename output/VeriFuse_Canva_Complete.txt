## Slide 6 — MODEL ARCHITECTURE

**On-slide content**

Image → frozen CLIP image encoder → 512 features  
Caption → frozen CLIP text encoder → 512 features

Feature fusion combines:

- Image and text embeddings
- Absolute difference between embeddings
- Elementwise product
- Cosine similarity

**2,049 fused features → trained logistic regression head → REAL / FAKE score**

**Visual direction:** Editable two-branch architecture diagram. Both encoders feed a central fusion step, followed by the classifier. Mark the encoders “Frozen” and the head “Trained.”

**Speaker notes:** The exact fusion vector is [image, text, |image − text|, image × text, cosine(image, text)]. Its size is 512 + 512 + 512 + 512 + 1 = 2,049. The encoder is openai/clip-vit-base-patch32. Standardized classifier inputs use scalers fitted only on the training partition.

Source: verifuse/real_model.py; https://huggingface.co/openai/clip-vit-base-patch32

## Slide 7 — TRAINING AND FUSION STRATEGIES

**On-slide content**

| Method | Classifier input |
|---|---|
| Text only | 512 text features |
| Image only | 512 image features |
| Feature fusion | 2,049 image, text, and interaction features |
| Decision fusion | 0.8 × text score + 0.2 × image score |

- Train L2-regularized logistic heads on the training partition.
- Select regularization and the decision-fusion weight using validation log loss.
- Select feature fusion using validation performance.
- Evaluate once with a fixed classification threshold of 0.5.

**Visual direction:** Editable comparison table with the two fusion methods emphasized subtly.

**Speaker notes:** Regularization candidates were C = 0.001, 0.01, 0.1, 1, and 10. All three learned heads selected C = 0.001. The late-fusion weight was selected from a validation grid. The test labels were not used to select these settings. FAKE is the positive class. Scores are uncalibrated class estimates.

Source: results/real/experiments.json; models/real/bundle.json.

## Slide 8 — HELD-OUT TEST RESULTS

**On-slide content**

Evaluation on 1,415 real-media image-text pairs

| Model | Accuracy | FAKE F1 | Macro F1 | ROC-AUC |
|---|---:|---:|---:|---:|
| Always FAKE baseline | 80.35% | 0.8911 | 0.4455 | 0.5000 |
| Text only | 86.01% | 0.9178 | 0.7232 | 0.8703 |
| Image only | 80.85% | 0.8914 | 0.5412 | 0.8218 |
| Feature fusion | 88.62% | 0.9318 | 0.7943 | 0.9159 |
| Decision fusion | 85.58% | 0.9163 | 0.6992 | 0.8884 |

**Feature fusion improves accuracy by 2.61 percentage points over text alone.**

**Visual direction:** Editable results table, with feature fusion in blue. If a chart is included, plot macro F1 on a 0–1 axis using the same values.

**Speaker notes:** The majority baseline exposes the effect of class imbalance. Macro F1 weights the two classes equally. Feature fusion also has average precision 0.9766 and log loss 0.2818. Decision fusion does not beat text-only accuracy in this run. Differences are observed point estimates; no significance test or confidence interval was computed.

Source: results/real/report.md.
